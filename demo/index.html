A little Handwired experiment

Small counter.
Numeric circuit.

The buttons are ordinary HTML. The state changes run through Handwired.

0

Always between 0 and 20.

What’s happening?

Each click sets an event cell to 1. The circuit computes the next count, then resets the event cells to 0. JavaScript commits the new state and updates the page.

changed = count + increment − decrement
bounded = clamp(changed, 0, 20)
next    = reset ? 0 : bounded

That’s builder logic expressed as weighted sums, ReLUs and numeric selection—not a JavaScript counter hidden behind the buttons.

Using @skorotkiewicz/handwired@0.1.1 from npm. Just for us.
